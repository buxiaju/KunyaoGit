## 1. Ctrl+P 跳转文件（v0.5 P0.1）

### 1.1 打开方式

- [ ] 按 `Ctrl + P`（Mac: `Cmd + P`）打开文件跳转面板
- [ ] 按 `Ctrl + E` 也打开（VS Code 兼容）
- [ ] 按 `Ctrl + Shift + P` 仍打开**命令**面板（v0.4 既有，不冲突）
- [ ] 顶部 placeholder 切到「输入文件名跳转…」
- [ ] 顶部右侧模式徽标显示「文件」（FileText / Hash 图标）
- [ ] 命令面板和文件面板的 placeholder / 模式徽标正确区分

### 1.2 搜索性能与匹配

- [ ] 打开一个真实仓库（>= 100 个文件）→ 立即显示完整文件列表
- [ ] 输入"btn" → 列表过滤到含"btn"的文件，按匹配分数排序
- [ ] 匹配字符在结果中高亮成 emerald 绿
- [ ] 空结果时显示「没有匹配的命令」（文案来自 v0.4 复用，可改）
- [ ] 清空搜索词后恢复完整列表
- [ ] 5 千文件的仓库实测从打开到匹配结果 < 200 ms（用 5k+ 仓库或本地大仓库验证）

### 1.3 跳转行为

- [ ] 选中文件（上下键 + Enter）→ 面板自动关闭
- [ ] 仓库页自动切到「文件」Tab
- [ ] Monaco 编辑器加载该文件内容
- [ ] 侧边栏文件树中高亮显示该文件（如果已展开）

### 1.4 边界

- [ ] 无仓库时按 `Ctrl + P` → 不应打开（或打开但显示空）
- [ ] 在命令面板的「命令」模式下按 `Esc` → 关闭
- [ ] 在 input 聚焦时按 `Ctrl + P` → 仍触发（命令面板任何时候都可开）
- [ ] 在 input 聚焦时按 `Ctrl + R` → **不**触发刷新（输入框让位）

### 1.5 已知非 bug

- 中文 / 中文路径文件可搜索（实测中文 / 中划线 / 点 / 数字都支持）
- 文件名含空格也能匹配（git ls-files 用 NUL 分隔）
- 不会跳转到未跟踪文件的 Monaco 编辑器（仅 selectedFile 状态变化 + 切到 files tab；如果用未跟踪文件需要先 `git add`）

## 2. 文件历史（v0.5 P0.2）

### 2.1 入口

- [ ] 打开任意文件（如 `src/components/repo/EditorPane.tsx`）
- [ ] 顶部工具栏出现「历史」图标按钮（History 回滚钟表）
- [ ] 点击「历史」→ 右侧抽屉打开（560px 宽）
- [ ] 抽屉头部显示文件路径
- [ ] 抽屉默认空白（loading），约 100-500ms 后填充 commit 列表

### 2.2 commit 列表

- [ ] 每条 commit 显示：
  - message 第一行（截断）
  - 短 hash（emerald 绿）
  - 作者
  - 相对时间（如"3 天前"）
- [ ] 按时间倒序（最新在最上）
- [ ] 上限 50 条（看是否有滚动条）
- [ ] 大量 commit 时列表可滚动

### 2.3 展开 / 折叠 diff

- [ ] 点击任一 commit 行 → 展开 + 调 `git:file-diff`
- [ ] 展开后显示自实现 diff 渲染：
  - `-` 红行（删除）
  - `+` 绿行（新增）
  - ` ` 灰行（上下文）
- [ ] 重新点击同一行 → 折叠
- [ ] 第一次展开有"加载 diff" 旋转图标，~100ms 后显示
- [ ] 第二次展开（已缓存）→ 立即显示

### 2.4 边界

- [ ] 切换到不同文件 → 抽屉内容自动重置（不显示上一个文件的 history）
- [ ] 没有 commit 历史的新建文件 → 显示「暂无提交历史」
- [ ] 文件不存在（被删除）→ 抽屉显示「加载文件历史失败: <error>」
- [ ] Esc / 点击抽屉外部 → 关闭抽屉

### 2.5 已知特性

- `--follow` 自动跟踪重命名（文件改名后仍能查到历史 commit）
- 仅显示当前文件的 diff（不显示该 commit 的所有文件变化）
- 大 diff（> 1000 行）自动 max-h-96 + 内部滚动

## 3. Blame（v0.5 P0.2）

### 3.1 触发

- [ ] 打开任意文件（如 `electron/services/git.ts`）
- [ ] 等 100-500ms 后 blame 加载完成（切文件时重新加载）
- [ ] 鼠标点击 Monaco 编辑器**行号区域**（左侧 16px 行号 gutter）
- [ ] 屏幕右下角弹出浮窗

### 3.2 浮窗内容

- [ ] 显示：commit hash（短 7 位 + emerald 绿） + 作者 + 日期（YYYY-MM-DD） + 当前行号 + commit message 第一行
- [ ] 位置不挡代码（绝对定位 right-4 bottom-12）
- [ ] 再次点击任意处关闭浮窗
- [ ] 浮窗不阻塞其他点击

### 3.3 边界

- [ ] 大文件（5000+ 行）点击行号也能立即响应（O(1) Map 索引）
- [ ] 切换文件后 blame 重新加载（不显示上一个文件的 blame）
- [ ] 切到未保存的新文件（无 git 历史）→ 浮窗不显示（blameMap 为空）
- [ ] 多次快速切换文件 → 不抛错（异步竞态保护）

### 3.4 已知限制（v0.5 不支持）

- 点击 commit hash 不跳到历史 tab（v0.5 仅显示信息，v0.6 候选）
- 二进制文件 blame 不可用（git blame 默认行为）
- 极小行号（行 1）也能查到 blame
