## 1. v0.6.3 Bug #1：generateSshKey 空 keyPath 自动 fallback

**前置**：删除（或改名）`~/.ssh/id_ed25519_github` / `id_ed25519_gitee`（先备份）

### 1.1 空 keyPath + 有 host

- [ ] 打开「设置 → SSH 推送」区
- [ ] 点「生成新密钥」（GitHub 行）→ 表单弹窗
- [ ] 私钥文件名留空 → 提示「将自动落到 `~/.ssh/id_ed25519_github`」
- [ ] 点「生成」→ 私钥自动落在 `C:\Users\<user>\.ssh\id_ed25519_github`（**不报错**）
- [ ] 公钥自动复制到剪贴板
- [ ] 同样流程走 Gitee 行 → 私钥落在 `~/.ssh/id_ed25519_gitee`

### 1.2 空 keyPath + 无 host

- [ ] 假如前端某条路径没传 host（开发者改 UI 时漏传），后端应 throw 明确错误：
  `"keyPath 为空时必须传 host"`（看 DevTools console / toast 错误）
- [ ] **不**应再出现旧的 `'keyPath 不能为空'` 这种无语义错误

### 1.3 显式 keyPath

- [ ] 手动指定别的路径（如 `~/test_key`）→ 落在这个路径（不强制加 `_github` / `_gitee` 后缀）
- [ ] host 字段不参与（即使填了 github.com，key 文件名也不被追加后缀）

## 3. v0.6.3 Bug #3：SSH 已存在密钥列表 + 删除

**前置**：在 `~/.ssh/` 下放几个测试私钥（如 `id_ed25519_test_1` / `id_rsa_test_2` / `id_ed25519_github`）

### 3.1 列表显示

- [ ] 进入「设置 → SSH 推送」→ 顶部出现「已存在的 SSH 私钥」卡片
- [ ] 列表显示 `id_ed25519_github` 一行：文件名 + `github.com` 紫 badge + fingerprint（形如 `SHA256:...`）+ 「✓ 使用此 key」按钮 + 「🗑 删除」按钮
- [ ] `id_ed25519_test_1`（无后缀）：显示 `?` badge（无法推断 host）+ 同样按钮
- [ ] 不应出现 `id_rsa` / `id_ecdsa` 等已配对但 fingerprint 计算失败的项报错（应静默跳过）

### 3.2 使用此 key

- [ ] 点 `id_ed25519_test_1` 行的「✓ 使用此 key」→ 路径自动填入下方的 GitHub 字段
- [ ] 点「测试 GitHub 连接」→ 用该 key 测连接（成功 / 失败按实际，但**不应**因为路径不合法报错）

### 3.3 删除（重点 — 二次确认 + 安全护栏）

- [ ] 点任一行的「🗑 删除」→ 弹出确认窗「确定删除 {filename} 吗？此操作不可撤销。」
- [ ] 点「取消」→ 文件仍在
- [ ] 再点「🗑 删除」→ 点「确定」→ toast「已删除 {filename}」→ 列表实时刷新
- [ ] 打开 `~/.ssh/` 确认**私钥和公钥都被删除**（成对删除）
- [ ] 0600 权限不变（OpenSSH 不会因此拒认）

### 3.4 安全护栏（开发者视角）

- [ ] 后端日志 / DevTools console 不应暴露「尝试删 /etc/」之类的失败路径（路径在 `~/.ssh/` 外应直接被拒）
- [ ] 单元测试 `deleteSshKey` 6 例应全绿（已自动跑过 — 见 §9）

## 12. 已知 v0.6.3 限制 / 未实现

- [ ] SSH 私钥 passphrase 仍**不支持** UI 输入（默认空）。需要 passphrase 的用户手动 `ssh-keygen -p -f <key>` 重新加密；v0.6.4 候选
- [ ] SSH 私钥生成后没自动 `ssh-add`，需用户手动 `ssh-add ~/.ssh/id_ed25519_github` 或重启 ssh-agent
- [ ] Gitee SSH 响应格式与 GitHub 不同（不一定含 `Hi <user>!`），已加 stdout+stderr 合并检测但成功率仍比 GitHub 低
- [ ] 附件上传无进度条（v0.7 候选）
- [ ] `preferredProtocol: 'ssh'` 模式当前不做"自动改 remote + push + 还原"的临时切换（v0.7 候选）
- [ ] Gitee 仓库 git 体积 829.9MB / 819MB 软警告（v0.6.3 NSIS 不入库；v0.6.4 前必须决方案）
